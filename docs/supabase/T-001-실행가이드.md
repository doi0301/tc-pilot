# T-001: Supabase 프로젝트 및 스키마 적용 — 실행 가이드

## 완료 조건
- [ ] Supabase 프로젝트 생성
- [ ] projects, specs, test_cases, issues 4개 테이블 생성
- [ ] `.env.local`에 URL, anon key 설정

---

## Step 1: Supabase 프로젝트 생성

1. [Supabase Dashboard](https://supabase.com/dashboard) 접속
2. **New Project** 클릭
3. 다음 입력:
   - **Name**: `tc-pilot` (또는 원하는 이름)
   - **Database Password**: 안전한 비밀번호 설정 (저장해 두세요)
   - **Region**: 가장 가까운 리전 선택
4. **Create new project** 클릭
5. 프로젝트 생성 완료까지 1~2분 대기

---

## Step 2: 스키마 실행

1. Supabase 프로젝트 대시보드에서 **SQL Editor** 메뉴 클릭
2. **New query** 클릭
3. `docs/supabase/schema.sql` 파일 내용 전체 복사
4. SQL Editor에 붙여넣기
5. **Run** (또는 Ctrl+Enter) 클릭
6. 성공 시 "Success. No rows returned" 메시지 확인

---

## Step 3: 테이블 생성 확인

1. **Table Editor** 메뉴 클릭
2. 다음 4개 테이블이 보이는지 확인:
   - `projects`
   - `specs`
   - `test_cases`
   - `issues`

---

## Step 4: 환경변수 설정

1. **Project Settings** (톱니바퀴) → **API** 탭
2. **Project URL** 복사 → `.env.local`의 `NEXT_PUBLIC_SUPABASE_URL`에 입력
3. **Project API keys** > **anon public** 복사 → `NEXT_PUBLIC_SUPABASE_ANON_KEY`에 입력

---

## RLS (Row Level Security) 참고

MVP에서는 RLS를 비활성화한 상태로 진행합니다. Supabase 기본 설정상 새 테이블은 RLS가 꺼져 있으므로 별도 조치가 필요 없습니다.

나중에 인증을 추가할 경우, Table Editor에서 각 테이블의 RLS를 활성화하고 정책을 설정하면 됩니다.
