## 대용량 기획서(PPTX) 업로드 가이드

현대제철 기획서처럼 슬라이드 수가 많은 PPTX 파일은 한 번에 모두 업로드하면 AI 품질이 떨어지거나 JSON 파싱 오류가 발생할 수 있습니다. 아래 권장 방법을 따라 주세요.

### 1. 섹션(챕터) 단위로 나누기

- 기획서의 목차를 기준으로 자연스러운 단위를 정리합니다.
  - 예: `1장 사업 개요`, `2장 요구사항 정리`, `3장 화면 설계`, `4장 테스트 시나리오` 등
- 각 섹션을 별도 PPTX 파일로 저장합니다.
  - 원본 PPT에서 해당 슬라이드 범위를 선택 → "다른 이름으로 저장" → 새 PPTX 파일 생성
  - 섹션당 슬라이드 수는 **20장 이하**를 권장합니다.

### 2. 업로드 탭에서 섹션별로 순차 업로드

- TC Pilot의 `업로드` 탭에서, 위에서 나눈 각 섹션 PPTX 파일을 **한 번에 하나씩** 업로드합니다.
- 섹션마다 다음을 반복합니다.
  1. 섹션 PPTX 업로드
  2. 스펙 변환 결과를 확인/수정
  3. `생성 TC` 탭에서 해당 스펙으로 테스트 케이스 생성

### 3. 어떤 슬라이드를 포함할지 기준

- **포함하는 것이 좋은 슬라이드**
  - 화면 설계/와이어프레임, 버튼·입력필드가 나열된 화면 설명
  - 업무 플로우, 상태 전이 다이어그램
  - 입력/출력 항목, 검증 규칙이 표로 정리된 슬라이드
- **가능하면 제외해도 되는 슬라이드**
  - 회사 소개, 프로젝트 배경/목표, 일정, 팀 구성
  - 이미 다른 섹션에 중복된 내용

### 4. parseOnly(파일 내용만 먼저 보기) 활용

- `파일 내용만 먼저 보기 (AI 사용 안 함)` 옵션을 켜고 업로드하면,
  - PPTX에서 추출한 텍스트를 슬라이드 번호와 함께 확인할 수 있습니다.
- 이 미리보기로 "어디까지를 하나의 섹션으로 묶을지" 감을 잡은 뒤,
  - 실제 스펙 변환 시에는 섹션 단위의 PPTX로 나누어 올리는 것을 추천합니다.
